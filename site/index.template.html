05 — THE WORK SPEAKS

Sixteen presets.
One brief. Play them all.

In September 2026, sixteen eagent presets built the same modern Breakout spec, most of them unattended and in parallel: sixteen playable games for about $242 in list-price spend. Two hero-tier runs top the table below, and a resumed run's nebula fix turned last round's black canvas into a shared perfect score. Every build below is staged from its run, with its measured cost, rubric score, and an honest label where it breaks.

Documented September 2026 runs on binary v0.8.0-1-g59ce5c7. Costs use September 2026 list prices; these are individual observations, not performance guarantees. Each game was served statically and played with scripted Chromium at desktop and phone viewports, then scored against the same nine-item rubric (27 points) from code reading plus that play. Statuses: done (the run declared itself finished), stopped · budget (passed verification, then the budget stopped it), stopped · cap (a cost cap killed it mid-verification), halted · provider (provider errors ended it). A LITTLE MORE CONTEXT

Good questions.

Read the full documentation
What does it cost?+

eagent is free, open-source software under the MIT license. You pay your model providers for API usage. The web UI reports input, output, cached tokens, and estimated cost per actor; totals are marked partial when a model’s price is unknown. Actual cost depends on the task, models, and cache usage.

Can I use a local model or mix providers?+

Yes. Each actor has its own route, model, reasoning effort, and optional fallback. eagent supports OpenAI-compatible Chat Completions, OpenAI Responses, and Anthropic Messages protocols. Configure a compatible local server with its base URL and model name in the project’s JSON configuration.

Where does my session live?+

Under .agents/eagent/sessions/ in your project, as timestamped JSONL files. There is no session database to run. Your configured model providers receive the prompts and tool results they need to do the work. Finalechat conversation mirroring is optional, and native transcript publication requires a separate opt-in.

Does a fresh context lose the original history?+

The original logs stay on disk. On orchestrator rollover, a worker builds a dossier from the previous subsessions, with citations back to the full events. The orchestrator can follow those citations using session-reading tools. Workers start fresh per task; only the orchestrator has the dossier rollover mechanism.

Are commands sandboxed?+

Commands run on your machine with your user’s privileges. eagent does not provide a sandbox. Its file tools constrain writes by default, but bash can perform anything your account can. Run it in a workspace and environment appropriate for the task.

Can I customize more than the models?+

Yes. Tune task concurrency, call budgets, narration cadence, context rollover, shell deadlines, and the narrator’s voice. Export and edit the embedded Markdown prompts, keep named configuration bundles in the project, or use the graphical editor. The orchestrator can also create timers, loops, and cron schedules for ongoing work.

What happens if a provider fails?+

Transient errors retry with backoff. Unroutable requests, including exhausted credits, move to a configured fallback for any actor. A worker failure is reported to the orchestrator for follow-up. If orchestrator recovery also fails, the session pauses with its history intact so you can resume it.
