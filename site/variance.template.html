BREAKOUT VARIANCE — 33 REPEATS

Same Breakout.
Thirty-three times.

After the sixteen-preset Breakout grid, we re-ran the cheapest builds ten times each to see what repeats actually cost. Four lanes, forty runs, thirty-three finished games — every one below is staged from its run and playable in place, with its measured cost and build time.

Same spec and one-line prompt, fresh directories, EAGENT_FINALECHAT=off, binary v0.9.0-dirty (the original grid ran v0.8.0-1-g59ce5c7-dirty). Per-run caps of $2 (muse) / $3 (everything else) were never breached; total variance spend ≈ $23.80 in catalog list-price estimates. No rubric re-judging: this is cost / duration / completion variance, not score variance. Per-lane means in the table below are done-only (finished runs); the writeup quotes slightly different headline figures for two lanes because those fold the timeout-capped runs in. Each game was served statically and screenshotted with scripted Chromium at desktop and phone viewports. The live 16-game gallery is untouched — this page is a separate annex.

What actually varies (and what doesn’t)

  1. The grid headline survives with error bars. The 4-cent muse build is also the most consistent: 10/10 finished, a 5-cent cost band ($0.031–$0.078), fastest at ~16 minutes average. Cost predicts nothing; convergence does.
  2. Same models, different pipes. The identical GLM-shaped preset averages $0.78 ± $0.31 on Fireworks vs $0.92 ± $0.59 on OpenRouter — the provider adds about a fifth and nearly doubles the spread (ranges $0.34–$1.43 vs $0.56–$2.30).
  3. The variance driver is verification depth, not building. All 7 timeouts (0 on muse) were QA workers iterating open-endedly — screenshot staring, soak loops, fix-and-check cycles — with the finished game sitting on disk. Stalled runs were supervisor-stopped at 90 minutes, sessions parked resumable. Muse’s loop converges: check → screenshot → fix N things → ship.
