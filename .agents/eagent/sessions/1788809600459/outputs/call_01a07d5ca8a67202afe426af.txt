4 · Verdict

Ranking (by rubric total, ties broken by judgment): 1. anthropic-high (27) · 2. anthropic-med (27) · 3. glm (26) · 4. openai-high (26) · 5. openrouter-high (26) · 6. openai-low (18).

The single best build is anthropic-high (TOPSIDE) — and it is close: anthropic-med matches it point-for-point at 27/27 and was the most fun in actual play (score 7,114 vs 104). anthropic-high edges it on breadth-and-polish: a passing test suite including multiplier-hysteresis and tier checks, a clean dependency-free architecture, and the most dependable play experience end to end. If you weight “best demonstrated game” over engineering quality, swap the top two — that is genuinely a coin-flip. The three-way tie at 26 is also close: glm has the deepest feature list, openai-high the strongest identity/HUD, openrouter-high the cleanest code.

5 · Methods & caveats

Metrics were parsed from each run's JSONL event logs (per-actor model calls, tokens, cache hits, costs, task lifecycle, narrator messages, errors).

Costs are at list prices; they are heavily influenced by prompt-cache economics — the Anthropic presets ran at ~93–95% cache ratio and openai-high at only ~6%, so cross-vendor comparisons are not apples-to-apples.

Play was scripted Playwright automation (mouse sweeps, scripted touch drags), not a human. Caveats: openrouter-high's ball never launched (tap/click/Space all failed in the script — possibly an automation artifact, possibly a real input bug); openai-low got paused by the script's own Space press on desktop; everything else launched and played cleanly.

All six games loaded and played with zero console and zero page errors in automated Chromium (desktop 1280×800 and mobile 390×844 touch).

Rubric scores come from code reading plus automated play, not from a blind human review.

Sound was never heard — the play harness was headless; audio scores are based on code only.

FPS was not measured except where a build's own test suite reported it (glm's harness reported ~61 FPS).

Source metrics: openai-low's source is minified (~34 physical lines, ~10 KB game.js) — real code, just minified; openrouter-high's run log had 1 error (first task died on an API 404 — no image-capable endpoint — 1 of 2 tasks completed, but the final game still works).
